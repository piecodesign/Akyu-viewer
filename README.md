# 名人戦A級 5局ビューワー

RenjuPortal に日本連珠社が登録した名人戦A級リーグの棋譜を、ラウンドごとに5局並べて表示するページです。

## しくみ

- GitHub Actions が5分おきに RenjuPortal の棋譜一覧を取得し、`data/games.json` に保存します。
  - 対象：作成者が日本連珠社（renjusha）で、`config.json` の10名同士の対局
- ページは棋譜の作成時刻と `config.json` の日程を照らしてラウンドを判定します。
  - 各ラウンドの開始90分前から、次のラウンドの開始90分前までに作られた棋譜を、そのラウンドとみなします（棋譜に「R◯」が書かれていなくても判定できます）。
- 「最新（自動）」を選んでいると、新しいラウンドの棋譜が出たときに自動で切り替わります。プルダウンで過去のラウンドも見られます。
- 盤面は RenjuPortal のページそのものを埋め込んでいるので、対局中も自動で手が進みます。

## 最初の設定（1回だけ）

1. GitHub で新しいリポジトリを作る（公開＝Public）。
2. このフォルダの中身を全部アップロードする。`.github` フォルダは Mac の Finder では隠れているので、`Cmd + Shift + .` で表示してから一緒に入れてください。
3. リポジトリの **Settings → Pages** で、**Source** を **GitHub Actions** にする。
4. **Actions** タブを開き、「棋譜一覧の更新と公開」を選んで **Run workflow** を押す。
5. 1〜2分後、`https://ユーザー名.github.io/リポジトリ名/` で見られます。

## 日程や選手が変わったとき

`config.json` を GitHub 上で編集して保存してください。保存すると自動で公開し直されます。

- `rounds`：各ラウンドの開始時刻（日本時間）
- `players`：対象の選手名（空白の有無は気にしなくて大丈夫です）
- `leadMinutes`：開始何分前からそのラウンドとみなすか（初期値90分）
- `until`：この時刻を過ぎたら取得を止める

## 注意

- GitHub の定期実行は混み具合で数分〜十数分遅れることがあります。新ラウンドへの切り替わりがその分遅れることがあります。
- 大会が終わったら、Actions タブで「棋譜一覧の更新と公開」を **Disable workflow** にしておくと安心です（期間外は取得しない作りにはなっています）。
- 取得が失敗しているときは、Actions タブの実行記録に赤い×が付きます。
